Today’s big question

What story does the data tell, and which graph makes that story easiest to see?

Start with the question

The best graph depends on what you want to know.

Compare categories

Column chart

Which class read the most?

Show a ranking

Horizontal bars

Which club ranks first?

Compare totals + parts

Stacked bars

How is each total divided?

See a distribution

Histogram

Which range occurs most often?

Show parts of one whole

Pie chart

What percent belongs to each part?

Investigate a relationship

Scatter plot

Do two numerical variables move together?

Show change in order

Line chart

How does a value change over time?

Question first → graph second → evidence always.

Graph family 1

Three bar charts. Three different jobs.

Vertical / column

Compare values across separate categories. The bars have gaps.

Horizontal

Show a ranking or make long category names easy to read.

Stacked

Compare the total bar and the colored parts inside each total.

Watch out: A stacked bar is not just decoration—the segments must represent meaningful parts.

Graph families 2 + 3

Ranges touch. Parts make a whole.

Histogram = distribution

  • Uses continuous numerical ranges
  • Bars normally touch
  • Reveals the most common range and overall shape
VS

Pie chart = one whole

  • Every slice belongs to the same whole
  • All percentages total 100%
  • Works best with a few clear slices

Graph families 4 + 5

Connected sequence or paired relationship?

Line chart

  • Shows change over time or another ordered sequence
  • Points connect because their order matters
  • Example: temperature by day
VS

Scatter plot

  • Compares two numerical variables
  • Each point is one paired observation
  • Points are not connected in time order

Decision test: Does order connect the observations, or does each point pair two numerical values?

Quick check

Name that graph.

Say your answer first. Then reveal it.

A teacher groups quiz scores into 50–59, 60–69, 70–79, 80–89, and 90–99. Which graph best reveals the distribution?

You have study hours and quiz scores for each student. Which graph best investigates whether the two variables are related?

You recorded the temperature each day from Monday through Friday. Which graph best shows how it changed in time order?

Summative #5 · Chart Presentation

Your mission: choose, build, and explain one graph in one minute.

  • Choose the graph that matches the data and investigation question.
  • Show the final graph created in Canva.
  • Name both variables and units.
  • Explain the pattern and one comparison.
  • Identify the valid outlier.
  • State the correlation and its limitation.
  • Answer one question using chart evidence.

Do not choose by appearance. Identify the data structure and the question first; then justify your graph choice.

Tell the evidence story

Pattern. Comparison. Outlier. Conclusion.

1

Pattern

Name both variables, the direction, and numerical evidence.

“As ___ changes from ___ to ___, ___ generally…”

2

Comparison

Name two different IDs and give accurate values for both.

“ID ___ has ___ and ___, while ID ___ has…”

3

Outlier

Name the valid outlier, both values, and how it differs.

“ID ___ is unusual because…”

4

Conclusion

State the relationship, correlation direction, and limitation.

“The chart suggests ___ correlation, but…”

Correlation can suggest a relationship. It cannot prove that one variable caused the other.

Organize the presentation

A clear minute has four moves.

0–10 sec

Introduce

Give the title and explain the data context. Name both variables and units.

10–30 sec

Read the pattern

Describe the direction and compare two IDs using exact values.

30–45 sec

Explain the outlier

Name it, give both values, and explain why it is away from the pattern.

45–60 sec

Conclude

State the correlation and say that it cannot prove causation.

Practice aloud with the chart on screen. Do not read a paragraph from the slide.
